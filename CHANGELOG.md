# Catatan rilis

## v1.0.0 — 17 September 2026

Rilis distribusi pertama dari revisi `quality-review-v2`.

- 55.376 entri terjemahan untuk subtitle, percakapan, NPC, serta teks dan tujuan quest dalam inventaris paket.
- Peninjauan bahasa terakhir memperbaiki 1.989 entri sumber pada 666 ARC.
- Arsip UI umum asli dipertahankan setelah masalah pemuatan font dan ikon; 89 label layanan NPC tetap menggunakan teks asli.
- Installer memeriksa kecocokan client, membuat cadangan terverifikasi, dan menyediakan pemulihan English.
- Paket distribusi hanya membawa patch, manifest, dokumentasi, dan skrip pemasangan/pemulihan.

Pemeriksaan struktur dan hash file telah dilakukan. Pengujian ulang seluruh adegan dan tata letak di dalam game belum selesai.
